**Goal:** Deliver an interactive, responsive date-planning prototype and a local recommendation API.

**Architecture:** Browser ES modules render shared state; independent planner functions enforce constraints. Node serves allowlisted static files and JSON APIs on loopback.

**Tech Stack:** Node built-ins, HTML, CSS, JavaScript, native SVG.

**Spec:** ../specs/2026-09-21-dayfold-design.md

## Global Constraints
- Clearly label sample data and demo login; no real external AI/map/auth claims.
- Browser storage only for profile and saved courses; no passwords or precise location retained.
- Mobile support at 390 px and desktop at 1440 px.
