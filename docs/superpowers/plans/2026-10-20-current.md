## 다음 작업과 완료 기준

1. 변경 diff 검토 후 GitHub에 커밋·푸시한다. 연결된 Railway 자동 배포의 성공 여부를 확인하고 운영 주소에서 로고·테마·지도 추적을 검증한다. 현재 미완료.
2. 실제 사용자로 가입 메일 수신·인증·로그인·프로필 수정·코스 저장·재로그인 복원을 확인한다. 테스트용 자격증명을 문서에 적지 않는다.
3. Android Chrome 및 iPhone Safari에서 설치·실행·업데이트·오프라인 안내를 실기기로 확인한다.
4. 두 테스트 계정의 DB 접근 격리를 검증한다. 다중 인스턴스가 필요하면 메모리 세션의 공유 저장소 이전을 별도 설계한다.
5. 네이티브 배포가 필요할 때만 `mobile/config.json`의 HTTPS 서버 설정, 새 APK/IPA 빌드·서명·실기기 검증을 진행한다. 현재 apiBase는 비어 있어 오프라인 샘플 빌드이다.

## 범위와 제약

이번 변경에는 DB 마이그레이션이 없다. 실제 업체 사진·가격·영업 여부를 보장하지 않는다. 추천 일정 추정과 실제 경로 조회 시간은 서로 다르다. 제휴 쿠폰·다국어·공공 관광 연계는 향후 확장 아이디어이며 현재 구현 완료 기능이 아니다.
