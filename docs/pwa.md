# 설치형 웹앱 (PWA)

현재 앱은 같은 Node 서버에서 웹 화면과 API를 제공하는 설치형 웹앱입니다.
`npm start` 실행 후 로컬에서 확인할 수 있습니다. 휴대폰에서는 공개 HTTPS 주소가 필요합니다.

## 배포에 필요한 설정

- 기존 Dockerfile 또는 Node.js 22 이상에서 `node server.mjs` 실행
- HOST=0.0.0.0, PORT는 호스팅 서비스의 지정값
- APP_MODE=live, APP_ORIGIN=https://실제서비스도메인
- 기존 .env의 Gemini·카카오·Supabase 설정은 호스팅의 비밀 환경변수에 입력
- 카카오 JavaScript 웹 도메인과 Supabase 인증 복귀 주소에 실제 HTTPS 주소 등록
- 현재 세션은 서버 메모리에 있으므로 단일 인스턴스로 운영하며 재시작 시 재로그인 필요

## 설치와 업데이트

Android Chrome 메뉴의 앱 설치 또는 홈 화면에 추가, iPhone Safari 공유 메뉴의 홈 화면에 추가를 사용합니다.
상단 앱 설치 버튼에서 설치 또는 안내를 열 수 있습니다. 새 웹 배포는 앱을 다시 열거나 새로고침하면 반영됩니다.
서버가 꺼져 있거나 오프라인이면 안내 화면을 표시합니다. AI와 지도는 인터넷이 필요합니다.
서비스 워커에는 공개 오프라인 안내 문서만 저장하며 계정·프로필·코스·API 응답은 캐시하지 않습니다.
