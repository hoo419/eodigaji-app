# 어디가지 베타 — 무료 서비스 연결

연동 코드는 준비되어 있지만 현재 계정 키는 입력되지 않았습니다. 무료 플랜도 본인 계정에서 키를 발급해야 하며, 공용 키를 제공하는 방식은 아닙니다. 이 문서는 2026-09-21 공식 문서를 확인해 작성했습니다.

## 1. Gemini: AI 대화

1. [Google AI Studio API 키](https://aistudio.google.com/apikey)를 열고 본인 Google 계정으로 로그인합니다.
2. 사용할 프로젝트에서 키를 발급합니다. 무료 요금제로 시작하고, 프로젝트의 실제 허용 모델과 호출 한도를 확인합니다.
3. 프로젝트 루트의 `.env`에서 `GEMINI_API_KEY=` 뒤에 키를 붙여 넣습니다. `AI_PROVIDER=gemini`는 그대로 둡니다.
4. 기본 모델은 `gemini-3.8-flash`입니다. 계정에서 다른 무료 지원 모델을 사용하려면 `GEMINI_MODEL`을 해당 모델 ID로 변경합니다.

[공식 요금](https://ai.google.dev/gemini-api/docs/pricing)에 일부 모델의 무료 입력·출력이 안내되어 있습니다. 무료 쿼터와 모델 가용성은 계정에서 확인해야 합니다. 무료 이용 내용은 Google 제품 개선에 사용될 수 있으므로 과제용 예시 데이터로 검증하세요. 이 앱은 이름·이메일·정확한 위치를 AI 요청에 자동 첨부하지 않습니다. 사용자가 대화에 직접 쓴 내용은 AI 서비스로 전달됩니다.

## 2. 카카오: 장소 검색과 지도

1. [카카오디벨로퍼스](https://developers.kakao.com/console/app)에서 앱을 만듭니다.
2. 카카오맵 API 사용 설정과 무료 쿼터 적용 여부를 확인합니다.
3. Web 플랫폼/허용 도메인에 `http://127.0.0.1:4173`과 필요하면 `http://localhost:4173`을 등록합니다. 메뉴 명칭은 콘솔 버전에 따라 다를 수 있습니다.
4. REST API 키를 `.env`의 `KAKAO_REST_API_KEY`에 입력합니다.
5. JavaScript 키를 `KAKAO_JAVASCRIPT_KEY`에 입력합니다. JavaScript 키는 지도 SDK에서 사용하는 도메인 제한 공개 키이며, REST 키와 다릅니다.

카카오의 [공식 가이드](https://apis.map.kakao.com/web/guide/)와 [무료 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota)를 확인하세요. 개발자 계정에서 처음 활성화한 지도 앱에 대한 무료 조건이 있습니다. 장소 검색은 이름·주소·좌표·전화번호·상세 링크를 제공하지만, 이 연동에서는 영업시간이나 실제 가격을 확인하지 않습니다.

## 3. Supabase Free: 이메일 로그인과 데이터 저장

1. [Supabase 대시보드](https://supabase.com/dashboard)에서 Free 조직과 프로젝트를 생성합니다.
2. 프로젝트 URL과 publishable key(또는 legacy anon key)를 `.env`의 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`에 입력합니다. **service_role 또는 sb_secret 관리자 키를 넣지 마세요.**
3. SQL Editor에서 `supabase/schema.sql` 내용을 실행합니다. 회원별 프로필·코스 테이블과 사용자별 접근 정책을 생성합니다.
4. Authentication에서 이메일 로그인을 설정하고 Site URL을 `http://127.0.0.1:4173`으로 지정합니다.
5. 이메일 확인이 켜져 있으면 가입 후 수신한 인증 링크를 열고 앱에서 다시 로그인합니다. Supabase 기본 이메일 발송에는 별도의 제한이 있으므로 [인증 제한](https://supabase.com/docs/guides/auth/rate-limits)을 확인하세요.

Free 요금제의 DB·인증·휴면 제한은 [공식 요금표](https://supabase.com/pricing)에서 확인합니다. `.sql` 파일을 만든 것만으로 DB가 생성되지는 않으며 프로젝트에서 실행해야 합니다.

## 4. 다시 실행하고 확인

서버 실행 터미널에서 Ctrl+C로 종료한 다음:

```sh
npm start
```

앱을 새로고침하고 상단 **서비스 설정**을 엽니다. `키 설정됨`은 키의 존재만 뜻하며 유효한 연결을 보증하지 않습니다. 실제 채팅, 지역 조건 변경, 회원가입/로그인, 코스 저장으로 각 연결을 확인합니다. 실패 시 API 응답 내용이나 비밀 키를 노출하지 않고 설정/한도 안내를 표시합니다.

키 입력 후에도 브라우저는 로컬 서버를 사용합니다. 클라우드에 공개 배포한 상태가 아닙니다. 현재 세션 저장소는 서버 메모리이므로 서버를 재시작하면 다시 로그인해야 합니다. 공개 서비스로 전환할 때는 배포 플랫폼·도메인·HTTPS·공유 세션 저장소·백업·운영 한도를 별도로 구성해야 합니다.

## 무료 한도와 앱 제한

- AI 요청은 앱 서버 기준 하루 기본 100회까지 허용하며 `.env`의 `AI_DAILY_LIMIT`로 낮출 수 있습니다. 공급자의 무료 한도가 더 낮으면 해당 한도가 먼저 적용됩니다.
- 이 제한은 단일 서버 메모리 기준이며 재시작 시 초기화됩니다. 공급자 과금 설정을 대체하지 않습니다.
- 외부 오류가 발생해도 유료 모델로 자동 전환하지 않습니다.
- 장소 검색은 지역별 5분 캐시를 사용합니다.
- 무료 플랜에서 사용할 모델·과금 활성화 여부는 계정 소유자가 확인해야 합니다. 코드만으로 계정의 청구 요금제를 변경하지 않습니다.

## 검증 범위

단위/HTTP 테스트에서 Gemini·OpenAI 응답 처리, 비밀 값 미노출, 키 누락, 장소 좌표 처리, 로그인 세션 쿠키와 사용자별 DB 요청을 검증합니다. 외부 응답은 테스트용 응답으로 대체하며 실제 키로 성공한 연동 시험은 별도입니다. 실제 DB의 RLS는 SQL 적용 후 두 테스트 사용자로 확인해야 합니다.
