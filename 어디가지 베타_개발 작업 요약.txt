1. 서비스와 기술
연인을 위한 데이트·여행 코스 추천 서비스입니다.
지역, 목적, 1인 예산, 시간, 분위기, 이동수단, 실내외 조건으로 코스를 추천합니다.
HTML/CSS/JavaScript 화면, Node.js HTTP 서버, Capacitor 8.5.2 Android/iOS 프로젝트로 구성됩니다.
AI는 대화에서 조건을 추출하고, 카카오가 실제 장소를 검색하며, planner가 코스를 조합합니다.
Supabase는 이메일·비밀번호 인증과 사용자별 프로필·코스 저장을 담당합니다.

2. 이번 작업에서 완료한 내용
- D:\앱 개발 프로젝트 코드와 기존 작업 요약을 불러왔습니다. 원래 다른 PC의 Codex 채팅은 복원하지 않았습니다.
- API 설정값 존재를 확인했습니다. 비밀 값은 기록하지 않았습니다.
- 로컬 서버를 외부 API 접속이 가능한 환경에서 실행했습니다.
- Gemini 및 카카오 실제 요청과 웹 코스 생성 성공을 확인했습니다.
- Gemini 무료 등급의 일일 20회 한도 도달을 AI Studio에서 확인했습니다.
- 사용자가 결제한 뒤 웹 채팅 성공을 확인했습니다.
- 실제 서비스 지역을 성수·연남·해방촌에서 국내 시·군·구·동네 직접 입력으로 확장했습니다.
- AI JSON 지역 enum과 서울 고정 검색 조건을 제거했습니다.
- 부산 해운대 AI 채팅·코스 생성, 수원 행궁동·제주 애월 장소 검색 성공을 확인했습니다.
- 샘플 모드는 기존 3개 지역만 지원하고 다른 지역 요청은 명시적 오류를 반환합니다.
- 회원가입 메일의 복귀 주소를 APP_ORIGIN으로 지정하고, 인증 결과 안내와 URL fragment 제거를 추가했습니다.
- 사용자 요청에 따라 Supabase Confirm email을 끈 뒤 mailer_autoconfirm=true, 이메일 로그인 활성화를 읽기 전용으로 확인했습니다.
- 가입 응답에 인증 토큰이 있으면 서버 세션 쿠키를 생성하여 즉시 로그인합니다.
- Supabase REST의 error_code를 처리해 비밀번호 불일치·미인증·메일 한도·가입 제한을 구분합니다.
- 환경변수가 샘플 HTTP 테스트에 영향을 주던 문제를 수정했습니다.
- iOS 플랫폼을 생성하고 App/Geolocation/Share 플러그인 및 공통 화면을 동기화했습니다.
- iOS 위치 권한 설명, 플랫폼별 위치 권한 요청, Android 전용 뒤로가기 처리 분기를 추가했습니다.
- Android와 iOS 버전을 0.2.0, 빌드 번호를 2로 맞췄습니다.

3. 현재 모바일 모드 — 반드시 확인
mobile/config.json의 apiBase는 빈 문자열입니다.
사용자가 공개 HTTPS 서버 없이 현재 소스로 빌드하도록 선택했습니다.
Android/iPhone 앱은 오프라인 샘플 모드로 실행됩니다.
실제 Gemini, 전국 카카오 장소 검색, Supabase 회원가입·로그인은 모바일에서 활성화되지 않습니다.
그 기능은 현재 PC의 웹 서버에서 동작하며, 모바일에는 공개 HTTPS 서버 연결 후 다시 빌드해야 합니다.
휴대폰의 127.0.0.1은 휴대폰 자신이므로 PC 웹 서버 주소로 사용할 수 없습니다.
.env의 비밀 API 키는 앱과 iOS 소스 ZIP에 포함하지 않습니다.

4. 주요 파일
public/app.js: 화면, 조건 입력, 대화, 가입·로그인, 프로필·코스 저장.
lib/planner.mjs: 조건 검증, 샘플 데이터, 코스 조합.
lib/connections.mjs: Gemini/OpenAI, 카카오 검색, Supabase HTTP 요청.
lib/sessions.mjs: 서버 메모리 세션 및 HttpOnly 쿠키.
server.mjs: 웹 및 API, 요청 검증, 호출 한도, 사용자 소유 데이터 접근.
mobile/entry.js / mobile/client.mjs: 네이티브 기능 및 온라인/오프라인 API 연결.
android/: Android 프로젝트. ios/: Xcode 및 Swift Package Manager 프로젝트.
supabase/schema.sql: 사용자별 프로필·저장 코스 및 RLS 정책.
docs/ios.md: Mac에서 iPhone 빌드·서명·실행 안내.
scripts/build-android.mjs: Android APK 생성.
dist-mobile/: 자동 생성되는 웹 번들. 직접 수정하지 않습니다.
